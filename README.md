\# Knights \& Demons - Simulación en C



Simulación de combate basada en el clásico juego Knights \& Demons, desarrollada íntegramente en ANSI C para la terminal. Este proyecto demuestra el manejo de lógica de estados y estructuras de datos básicas.



\## Características Principales

\* \*\*Sistema de Combate:\*\* Lógica de enfrentamientos por turnos calculando estadísticas de ataque, defensa y puntos de vida.

\* \*\*Gestión de Entidades:\*\* Uso de `structs` en C para modelar los atributos y el estado actual de los caballeros y demonios.

\* \*\*Interfaz por Consola:\*\* Bucle de juego interactivo utilizando flujos de entrada/salida (I/O) estándar.



\## Tecnologías Utilizadas

\* ANSI C

\* Compilador GCC

\* Bibliotecas estándar (`stdio.h`, `stdlib.h`)



\## Ejecución

1\. Clonar el repositorio: `git clone https://github.com/tu-usuario/knights-and-demons-c.git`

2\. Compilar el código: `gcc main.c -o knights\_demons`

3\. Ejecutar: `./knights\_demons`
